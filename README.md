# Maysonnave Imóveis — site público

Site estático gerado a partir do banco da Plataforma Mays. Não se edita à mão:
o conteúdo sai do sistema e o arquivo é regerado por `plataforma/site/gerar.py`.

**Ambiente de teste.** O endereço é provisório; o domínio definitivo entra depois.

Mostra apenas imóveis marcados como publicados. O formulário de contato grava
direto na tabela de leads do sistema.
